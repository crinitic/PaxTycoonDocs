# Gates
Every flight that departs from or arrives at your home airport needs a gate while it is on the ground. You only need gates at home: at every other airport, the gate comes with the route (rented or seasonal).

You start with one gate. Change the number of gates from **Airport > Gates**.

## Cost
- **Renting a new gate**: ¤1,000,000 once, per gate.
- **Rent**: ¤560,000 a month per gate, paid ¤20,000 every night.
- **Releasing a gate**: free, but there is no refund. Rent stops from that night.

## Gate agents
A gate only works if a [gate agent](../personnel/jobs/gate-agent.md) staffs it. A gate without an agent is still rented and still paid for, but sits idle. If an agent is off sick without replacement, you have one gate fewer for the day.

## How many gates you need
You need as many staffed gates as you have aircraft on the ground at home at the same time. If you don't have enough, flights are cancelled.

You cannot release a gate that this week's flights need. Change your schedule first.

## Terminals
Each terminal holds 10 gates. Terminal A is free. Once every gate in your terminals is rented, you can build the next one:

| Terminal | Gates | One-time cost |
|---|---|---|
| A | A1-A10 | Included |
| B | B1-B10 | ¤5,000,000,000 |
| C | C1-C10 | ¤10,000,000,000 |
| D | D1-D10 | ¤15,000,000,000 |

Each terminal costs ¤5,000,000,000 more than the last. Terminals have no rent, and you keep them even if you release their gates.

## Timetable
The **Timetable** tab shows which flight holds each gate at each moment of the day. A flight drawn in red means more aircraft are on the ground than you have staffed gates.

Gate numbers are only there to help you read the timetable. A flight can move to another gate when you change your schedule.
